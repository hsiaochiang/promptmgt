# UX 檢查腳本（Phase 7 / T037b）

## SC-009：首次體驗成功率
1. 以新使用者身份（清空 `db.json` 與 `Prompts/`）啟動 `npm run dev`。
2. 任務流程：設定 rootPath → 新增草稿 → 轉正為提示詞 → 編輯並儲存 → 插入片語。
3. 觀察：是否無阻塞完成任務；記錄失敗原因（路徑缺失、API 錯誤、UI 卡頓）。
4. 成功率目標：> 90%（3/3 走通）。

## SC-010：卡頓回報率
1. 於同流程中觀察交互延遲：
   - 大貼上（>100KB）是否顯示 loading（DraftEditor）。
   - 搜尋、列表切換是否 < 200ms。
2. 如有卡頓，記錄具體步驟與瀏覽器 Performance 標記。
3. 目標：卡頓回報率 < 10%（少於 1/10 操作可感卡頓）。
