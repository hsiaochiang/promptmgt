# UX 檢查與觀察（Phase 7 / T055–T060）

## 前置
- 以 `npm run dev` 啟動；使用 50/500 筆資料集與 1000+ 筆截斷場景各跑一次。
- 記錄工具：螢幕錄影 + 簡短備註；若可，附上 DevTools Performance trace。

## 檢查項目

- **SC-009 首次體驗成功率**：
   - 清空 `db.json` 與 `Prompts/`，或指向臨時 rootPath。
   - 任務：設定 rootPath → 新增草稿 → 轉正 → 編輯儲存 → 插入片語。
   - 5 次自測或 5 名使用者，成功率目標 ≥ 80%；記錄阻塞點（路徑缺失、API 錯誤、UI 卡頓）。

- **SC-010 互動卡頓/動畫遲滯**：
   - 在 100+、1000+ 筆資料下，觀察列表切換、開啟提示詞、複製、搜尋。
   - 若有 > 200ms 可感卡頓，記錄操作與 trace；目標卡頓回報率 < 10%。

- **SC-016 Inbox 淨空可見性**：
   - 完成 Inbox 工作後，淨空狀態文案/行動是否清晰；避免繼續工作混淆。

- **SC-017 Undo/Redo 易發現性**：
   - 在編輯器試用 Undo/Redo，確認快捷鍵可用、可被注意到，且不破壞焦點。

- **SC-018 Accordion 快捷鍵**：
   - 測試展開/收合快捷鍵是否存在且文件化，行為一致、無錯位。

- **SC-019 錯誤敘述可理解性**：
   - 觸發常見錯誤（檔案寫入失敗、搜尋截斷、衝突提示），文案需行動導向、避免技術行話。

- **SC-020 視覺延遲回饋**：
   - 在長操作（搜尋 1000+、大量載入）期間是否顯示忙碌/進度指示，避免誤判為卡死。
